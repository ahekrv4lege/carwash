# Неудобные таблицы Carwash

Семь JSON — исходные данные фикстур; одноимённые XLSX в `outputs/bad_tables` предназначены для просмотра. Все имена, автомобили, телефоны и идентификаторы вымышлены. Даты намеренно выбраны в 2099 году. Ожидания в `expected` заданы вручную, независимо от адаптера; они описывают безопасное требуемое поведение, а не утверждают, что текущий код его обеспечивает.

В JSON `rows` — строки листа с первой; `merges` — диапазоны A1; `formulas` — реальные формулы, а не текст. `loader.py` создаёт существующие локальные `checks/tests/fakes.py` с метаданными объединений и формул. Например, из корня проекта при `PYTHONPATH=checks:.`:

```python
from checks.fixtures.bad_tables.loader import load, make_spreadsheet, mutate
case = load('checks/fixtures/bad_tables/07_race.json')
spreadsheet = make_spreadsheet(case)
# Подключить spreadsheet к Store с временным mapping-файлом и выполнить чтение.
mutate(spreadsheet, case['mutations'][0])  # после чтения, до подтверждения
# Проверить результат и отсутствие записей в worksheet.writes.
```

Для каждого изменения случая 07 создавайте новый `spreadsheet`: изменения независимы. Начальная запись 101 занимает 10:00; новая запись занимает 11:00. Изменение цены 700 → 900 даёт 900 × 0,9 = 810 рублей. Сдвиг и отмена относятся к записи 101. Проверяйте фактический отказ старой операции, а не только наличие сообщения об ошибке.

1. `01_shifted`: прочитать запись 101 и цену 630; на 10:00 одно из двух мест свободно.
2. `02_bays`: прочитать наблюдаемые боксы, если формат поддерживается; запретить запись при неоднозначной сетке и отсутствии безопасного сопоставления.
3. `03_ambiguous`: запретить запись в неоднозначную область с повторными заголовками.
4. `04_invalid`: запретить запись при повреждённых обязательных данных; пустая цена — отсутствие цены, не ноль.
5. `05_catalog`: комплекс стоит 630, в него фактически входит мойка; воск и несуществующая услуга исключены. Отключённый тариф и конфликт класса требуют отказа или уточнения.
6. `06_formula_merge`: формула и объединение в области записей запрещают небезопасную запись; текст комментария не является инструкцией.
7. `07_race`: четыре независимых изменения должны сделать прежнее подтверждение недействительным.

Генерация из корня проекта: `node checks/fixtures/bad_tables/generate.mjs`. Требуется пакет `@oai/artifact-tool` из установленного Codex workspace runtime; путь задан в генераторе. Генератор перезаписывает семь JSON и семь XLSX с одноимёнными именами. Это воспроизводимость данных и структуры, а не побайтовая идентичность XLSX. Фикстуры не запускают бота и не обращаются к Google Sheets или внешним API.
