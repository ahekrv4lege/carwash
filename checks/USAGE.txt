Проверки Carwash — необязательная папка checks/

Из корня проекта:

python3 checks/run.py
python3 checks/run.py --live

Без флагов: все изолированные проверки. Настоящие .env и ключи не загружаются;
соединения и DNS запрещены. Telegram, AI и Google Sheets заменены синтетическими
транспортами только внутри тестов. Используется существующая .venv; пакеты
не устанавливаются. Код возврата: 0 — успех, 1 — провал теста, 2 — ошибка запуска.

--live: настоящий .env и реальные API. Проверяются Telegram getMe, webhook
и команды; Google Sheets читаются с OAuth scope spreadsheets.readonly, проверяется
каталог, расчёт цены, слоты и записи. На каждый настроенный AI-ключ отправляется
один запрос с настоящим production-инструментом get_price_list, лимит ответа
512 токенов. Этот режим расходует AI-квоту. Повторов неудачного AI-запроса нет.
Сообщения в Telegram не отправляются, polling не запускается, таблицы не меняются.

-v показывает название каждого теста. Без -v показываются прогресс и итог.
При ошибке: FAIL/ERROR, имя теста, файл:строка и причина. Для отдельного
изолированного теста можно передать его имя из строки ошибки:
python3 checks/run.py tests.test_providers.ProviderTests.test_existing_xkiro_defaults_are_preserved

Весь проверочный код, фикстуры и запускатель находятся внутри checks/.
Для удаления всех проверок достаточно удалить эту папку; приложение её не импортирует.

Последний прогон: 301 изолированная проверка прошла без ошибок и пропусков.
Живой прогон: 4 из 5 прошли. Telegram, Google Sheets, основной xKiro и Cloudflare
работают. Второй ключ xKiro получил AuthenticationError / HTTP 401 при генерации.
Список моделей с HTTP 200 не подтверждает доступ ключа к генерации.
Ключ не заменён и не скрыт из цепочки. --live честно завершается с кодом 1,
пока сервис не начнёт принимать этот ключ или пользователь не заменит его.

Параметры ожидания: AI_TIMEOUT_SEC=60 для одного API; AI_REQUEST_BUDGET_SEC=120
для всей цепочки. Наличие резервов не сокращает основному API его 60 секунд.
Готовый серверный .env содержит второй ключ xKiro закомментированным;
с ним отдельно прошли все четыре живые проверки действующих интеграций.
