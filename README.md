# Бот-администратор автомойки (aiogram 3 + Google Sheets + OpenRouter)

Клиент пишет боту обычным текстом. ИИ-администратор уточняет автомобиль, подбирает услугу или тариф,
называет точную цену, предлагает свободное время и записывает клиента — строка сразу появляется в Google-таблице.

**Как это устроено.** Нейросеть ничего не знает про цены и расписание «из головы». У неё есть
инструменты (tool calling), которые читают таблицу, считают стоимость и пишут запись.
Цены и свободные слоты считает код (`sheets.py`), поэтому модель не может ошибиться в сумме
или записать двоих на один слот.

## Быстрый старт

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
cp .env.example .env        # заполните значения
python setup_sheet.py       # (один раз) создаст листы-шаблоны в вашей таблице
python bot.py
```

### 1. Telegram
Создайте бота у [@BotFather](https://t.me/BotFather), токен — в `BOT_TOKEN`.
Свой Telegram ID (для `ADMIN_CHAT_ID`) можно узнать у @userinfobot.

### 2. Google Sheets API
1. [console.cloud.google.com](https://console.cloud.google.com) → создайте проект → **APIs & Services → Library → Google Sheets API → Enable**.
2. **IAM & Admin → Service Accounts → Create** → вкладка **Keys → Add key → JSON**. Сохраните файл как `credentials.json` рядом с ботом.
3. Создайте Google-таблицу, нажмите **«Поделиться»** и дайте доступ **Редактора** адресу `client_email` из `credentials.json`.
4. Id таблицы (часть ссылки между `/d/` и `/edit`) — в `SPREADSHEET_ID`.

### 3. OpenRouter
Ключ с [openrouter.ai/keys](https://openrouter.ai/keys) — в `OPENROUTER_API_KEY`. Модель — в `OPENROUTER_MODEL`.
Она **должна поддерживать tool calling** (на openrouter.ai/models включите фильтр по параметру `tools`),
иначе бот не сможет читать таблицу.

## Структура таблицы

`setup_sheet.py` создаёт всё сам, ниже — что значит каждый лист. Названия колонок можно писать в любом регистре.
Названия листов меняются через `.env` (`SHEET_SERVICES` и т.д.).

### Лист «Услуги» — цены по габаритам
| Услуга | Описание | Легковой | Кроссовер | Внедорожник/минивэн | Доступна |
|---|---|---|---|---|---|
| Мойка кузова | Бесконтактная мойка | 700 | 800 | 1000 | да |
| Горячий воск | Защитное покрытие | 500 | 600 | 800 | **нет** |

* Колонки между «Описание» и «Доступна» — **классы автомобилей**. Названия и количество любые:
  добавили колонку «Микроавтобус» — бот сразу начнёт её учитывать. ИИ сам относит модель клиента к классу.
* Пустая цена в колонке класса = услуга для этого класса не оказывается.
* **«Доступна» = нет** — администратор «убрал» услугу: бот её не предлагает и не записывает.

### Лист «Тарифы» — комплексы услуг
| Тариф | Состав | Скидка % | Доступен |
|---|---|---|---|
| Стандарт | Мойка кузова, Пылесос салона, Протирка салона | 10 | да |

* «Состав» — названия услуг с листа «Услуги» через запятую.
* **Цена тарифа = сумма цен входящих услуг для класса авто минус скидка.**
  Если администратор убрал услугу (Доступна = нет), тариф **автоматически пересчитывается без неё**,
  и бот честно говорит клиенту: «Сейчас в тариф не входит воск, цена — 1 395 ₽».
  Если убраны все позиции — тариф исчезает из предложений.
* «Доступен = нет» скрывает тариф целиком.

### Лист «Слоты» — когда можно записаться
| Дата | Время | Постов |
|---|---|---|
| 22.10.2026 | 10:00 | 2 |

* Одна строка = одно время начала. «Постов» — сколько машин можно принять одновременно.
* Чтобы закрыть время (обед, ремонт, выходной) — поставьте `0` или удалите строку.
* Свободно = «Постов» минус активные записи на это время. Прошедшие слоты и слоты ближе
  `MIN_LEAD_MINUTES` не показываются.
* Новые дни добавляйте строками (формат даты `ДД.ММ.ГГГГ`).

### Лист «Записи» — сюда бот пишет клиентов
`ID, Создано, Дата, Время, Имя, Телефон, Автомобиль, Класс, Тариф, Доп. услуги, Состав, Сумма, Комментарий, Telegram ID, Username, Статус`

* Статус при создании — «Новая». Меняйте как угодно («Подтверждена», «Выполнена»).
  Статус, начинающийся на **«Отмен…»**, освобождает слот.
* Порядок колонок можно менять, главное — не переименовывать их.

## Что умеет бот
* консультирует по услугам и тарифам, определяет класс авто по марке/модели;
* называет цену с учётом убранных позиций;
* показывает свободное время, понимает «завтра», «в субботу вечером»;
* перед записью повторяет детали и ждёт подтверждения клиента;
* записывает в таблицу, не допускает двойной записи на один слот;
* клиент может спросить «какие у меня записи» и отменить запись;
* уведомляет администратора в Telegram о новых записях и отменах (`ADMIN_CHAT_ID`);
* кнопка «Отправить номер телефона»; команды `/start`, `/reset`.

## Ограничения и заметки
* Одна запись занимает один слот. Если комплекс идёт дольше часа, делайте слоты реже (например, каждые 2 часа)
  или закрывайте следующий слот вручную.
* История диалогов хранится в памяти процесса — после перезапуска бот «забывает» разговоры (записи в таблице остаются).
* Лимит Google Sheets API — около 60 запросов/мин на сервисный аккаунт. Прайс кэшируется на 60 с, слоты на 15 с,
  при создании записи данные читаются свежими.
* Запускайте **один** экземпляр бота (защита от двойной записи работает внутри одного процесса).
* Для постоянной работы на сервере подойдёт systemd или Docker; 

## Файлы
| Файл | Назначение |
|---|---|
| `bot.py` | aiogram: приём сообщений, кнопка телефона, уведомления |
| `ai.py` | диалог с моделью через OpenRouter, описание инструментов, системный промпт |
| `sheets.py` | Google Sheets, расчёт цен и тарифов, слоты, запись/отмена |
| `setup_sheet.py` | создание листов-шаблонов с примером |
| `config.py` | настройки из `.env` |
