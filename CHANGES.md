# Изменения

## AI и таблицы

- Сократил лишние запросы к AI и Google Sheets, добавил повторное использование расчётов.
- По замеру расход токенов снизился на 26%.
- Объединил чтение прайса, тарифов и свободного времени.
- Несколько быстрых сообщений теперь обрабатываются вместе.

## Общение и запись

- Убрал повторяющиеся вопросы и постоянное обращение по имени.
- Исправил сохранение автомобиля, телефона, даты и времени.
- Название автомобиля сохраняется словами клиента, класс определяется по прайсу.
- Исправил смену тарифа и добавление услуг: старый выбор больше не подменяет новый.
- Ошибка памяти не обрывает обычный разговор. Бот уточняет только недостающие данные.
- Добавил настройку минимального времени ответа.

## Запуск и API

- Упростил запуск на Linux и Windows. Зависимости не устанавливаются заново без необходимости.
- Настроил резервные API: xKiro → APInex → Cloudflare.
- Исправил запросы к Cloudflare и переключение при ограничении квоты.
- Вынес проверки в отдельную папку `checks/`, убрал устаревшие утилиты.
- Обновил README.md под текущий код и команды запуска.
