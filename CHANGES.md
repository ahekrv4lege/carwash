# Изменения

## Запуск проверок на Windows (2026-10-26)

- Починил `checks/run.py` под Windows: добавил системные переменные окружения в белый список
  (gspread читает `APPDATA` при импорте) и сделал блокировщик сети с исключением для локальной петли —
  иначе self-pipe asyncio ронял все 244 асинхронных теста.
- Убрал случайный сбой бюджета AI-запроса на Windows: сравнение «остаток ≤ 0» заменил порогом
  одного тика монотонных часов (`MONOTONIC_RESOLUTION` в `ai.py`), т.к. тик таймера ≈16 мс.
- Растянул тайминги теста общего бюджета (`checks/tests/test_providers.py`) и перевёл тест блокировки
  сети (`test_check_commands.py`) на внешний адрес: бюджеты 0.02–0.04 с меньше тика таймера Windows,
  петля (127.0.0.1) больше не блокируется.
- Обновил тест инициализации SDK (`test_merge_regressions.py`): блокируем только внешние адреса.

## Испорченные таблицы (задача №4 из TODO.md)

- Добавил `checks/tests/test_corrupted_tables.py` (28 сценариев через общий
  `checks/tests/corruption_cases.py`): пустые поля, дубли, нестандартные заголовки, формулы,
  неверные цены — на листах «Услуги», «Тарифы», «Слоты», «Записи», включая офлайн-путь без адаптива.
- Исправил офлайн-путь прайса (`sheets.py`): отрицательная цена («-700») больше не превращается
  в отрицательную сумму (служба честно «не оказывается»), дублирующиеся колонки классов сшиваются.
- Зафиксировал тестами штатные ответы на порчу: мусорная цена выбрасывает колонку, формула читается
  как вычисленное значение, скидка >100% отказ, дубль строки слота суммирует посты, дубль ID записей
  и формула в записи дают внятные отказы.
- Добавил `checks/debug_tables.py` — отладочный отчёт «вход → результат» по всем сценариям
  (`checks/debug_tables_report.txt`), для запуска не нужны сеть и квоты.
