# Изменения

Исправления подготовлены поверх актуальной `dev` (`7e199af`). Правки команды сохранены,
включая удаление постоянной кнопки телефона. README не изменён.

- Восстановлены совместимость конфигурации и запуск; `.env.example` не нужен. OpenRouter удалён.
- Основной AI — xKiro, поддержаны второй ключ и Cloudflare. Модели выбираются явно.
- API-клиенты переиспользуются; отказавший API пропускается 60 секунд, затем получает одну пробу.
- Основной API сохраняет `AI_TIMEOUT_SEC=60`; общий бюджет цепочки — `AI_REQUEST_BUDGET_SEC=120`.
- Google повторяет только GET, максимум три попытки; записи после HTTP-сбоя не повторяются.
- Исправлены Ctrl+C на Windows, привязка доставки к конкретному предложению и длина админ-карточки.
- Сохранены адаптивные Sheets, batch-чтение, кэш, память, цены, слоты и подтверждения записи/отмены.
- Большие функции разделены по этапам, переменные переименованы по смыслу. Локального backend нет.
- Тесты вынесены в удаляемый `checks/`; демонстрационный генератор и `.env.example` удалены.
