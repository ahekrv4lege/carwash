# Изменения

- Обычный ответ AI больше не требует служебного вызова памяти. Ошибка отдельного
  необязательного поля не обрывает разговор; операции записи проверяются целиком.
- Слова клиента об автомобиле и распознанная модель разделены. Класс выбирается
  из фактического прайса, разговорные услуги сопоставляются с его названиями.
- Короткий контекст сохраняется в прежнем бюджете истории; расчёты используются
  повторно. Дни недели и время «в 11» распознаются без дополнительных AI-запросов.
- Приветствие сокращено, повторные обращения по имени убраны. Минимальное время
  ответа задаёт REPLY_MIN_DELAY_SEC=1.5; 0 отключает паузу. Время AI уже учитывается.
# Проверка

Все 337 изолированных тестов прошли; конфигурация и синтаксис Python 3.10
проверены. На одинаковом диалоге новая версия потратила на 26,4% меньше токенов,
чем предыдущая.

Полный тестовый разговор прошёл от выбора тарифа до подтверждения записи и
вопросов о цене и времени. Повторное подтверждение не создало дубль. Последняя
попытка дополнительного сценария остановилась из-за ограничения HTTP 429 у
xKiro. Полный разговор через Cloudflare ещё предстоит проверить.

Запуск: python3 run.py, ./start.sh или start.bat. Тесты: python3 checks/run.py;
--live проверяет настоящие интеграции и расходует AI-квоту.
