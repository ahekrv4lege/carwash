# Изменения

Сохранены изменения команды из dev, Telegram/aiogram, облачные AI API,
адаптивные Google Sheets, кэш и подтверждение записи/отмены. README не менялся.
Запуск: `python3 run.py`, `./start.sh`, `start.bat`; готовая .venv используется повторно.
OpenRouter, локальные подмены и демонстрационные файлы удалены; секреты вне Git.

## Исправление диалога

- AI получает явный формат памяти и одну попытку исправить ошибочный ответ.
  Автомобиль сохраняется словами клиента, без выдуманной марки и класса.
- Повтор старых фактов и пустые обновления не ломают диалог. Одиночная услуга
  и лишняя обёртка пары нормализуются; источник и прайс проверяются дальше.
- Предположения хранятся отдельно и не разрешают запись без уточнения.
  Убраны проверки источника для предположений и лишнее чтение каталога.
- Явно выбранная услуга не блокируется сбросом старого выбора.
  Выдуманный необязательный комментарий отбрасывается, остальные данные проверяются.
- Необязательные null-аргументы пропускаются; обязательные поля и кэш цен сохранены.
- Для Cloudflare HTTP 400/3030 «Invalid JSON» добавлена одна попытка respond
  в прежнем бюджете времени. Другие HTTP 400 не повторяются.
- Клиенты API переиспользуются; порядок xKiro → второй xKiro → Cloudflare сохранён.
  Основной API получает до 60 секунд, вся цепочка — до 120 секунд.

## Проверка

323 изолированных теста прошли без ошибок и пропусков. Проверки находятся
в удаляемой папке checks/. `--live` читает настоящий Telegram и Sheets,
проверяет каждый AI-ключ и полный диалог с AI на временной таблице.
Полный диалог через второй xKiro прошёл: предложение, подтверждение, время,
стоимость, свои записи и повторное подтверждение без дубля.
Первый xKiro вернул 429 с явным сообщением об исчерпании дневной бесплатной квоты.
Квота Cloudflare при проверке не исчерпана; ошибка 3030 связана с форматом ответа.
Общий live-прогон: 5/9 сценариев прошли, в том числе Telegram, Sheets и полный
диалог с записью на временной таблице. Первый xKiro: дневная квота; второй:
один сбой памяти, четыре повтора, включая тот же тест, прошли. Cloudflare: неверные инструменты,
HTTP 400/500; полный разговор пока не прошёл. Преждевременная запись блокируется.
Онлайн-бот и production Sheets не изменялись. Настоящий Windows не проверен.
